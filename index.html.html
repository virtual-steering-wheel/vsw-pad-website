Setup Guide

How to setup the Portable ZIP

  1. Download VSW-Windows-Receiver-Portable-v1.0.zip using the primary download button above.
  2. Right-click the downloaded `.zip` file and select Extract All... to unpack it into a folder of your choice.
  3. Open the extracted folder and run the receiver executable file.
  4. Ensure both your phone and PC are connected to the same local Wi-Fi network (or linked via USB Tethering).
  5. Open your game's controls menu and assign the mapped VSW inputs to your steering, throttle, and braking axes.
